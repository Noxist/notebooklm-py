📋 AI Prompt & JSON Format Specification (Click to open & copy for ChatGPT / Claude / Gemini)

Copy this specification and paste it into ChatGPT, Claude, or Gemini to have the AI write your batch files for you:

You are generating a JSON batch file for NotebookLM Batch Studio.

Output only valid JSON with this structure:
{
  "jobs": [
    {
      "id": "unique-kebab-case-id-001",
      "type": "",
      "notebook_id": "REPLACE_WITH_NOTEBOOK_ID",
      "title": "",
      "prompt": "",
      "language": "en",
      "when": "now",
      "options": {}
    }
  ]
}

Supported Types and Options:
1. audio
   - options.audio_format: "DEEP_DIVE" | "BRIEF" | "CRITIQUE" | "DEBATE"
   - options.audio_length: "SHORT" | "DEFAULT" | "LONG"
   - when: "now" | "later"

2. video
   - format: "EXPLAINER" | "BRIEF" | "CINEMATIC" | "SHORT"
   - options.video_style: "AUTO_SELECT" | "CUSTOM" | "CLASSIC" | "WHITEBOARD" | "KAWAII" | "ANIME" | "WATERCOLOR" | "RETRO_PRINT" | "HERITAGE" | "PAPER_CRAFT"
   - options.style_prompt: "string (only if video_style is CUSTOM)"
   - when: "now" | "later" (cinematic does not support later)

3. cinematic_video
   - prompt: "story prompt"
   - when: "now" (Generate Later unsupported)

4. report
   - format: "BRIEFING_DOC" | "STUDY_GUIDE" | "BLOG_POST" | "CONCEPT_EXPLANATION" | "CUSTOM"
   - prompt: "specific instructions or custom prompt"
   - language: "en" | "de" | "fr" (optional)
   - when: "now" | "later"

5. slide_deck
   - format: "DETAILED_DECK" | "PRESENTER_SLIDES"
   - options.slide_length: "DEFAULT" | "SHORT"
   - when: "now" | "later"

6. infographic
   - options.orientation: "LANDSCAPE" | "PORTRAIT" | "SQUARE"
   - options.detail_level: "CONCISE" | "STANDARD" | "DETAILED"
   - options.style: "AUTO_SELECT" | "SKETCH_NOTE" | "PROFESSIONAL" | "BENTO_GRID" | "EDITORIAL" | "INSTRUCTIONAL" | "BRICKS" | "CLAY" | "ANIME" | "KAWAII" | "SCIENTIFIC"
   - when: "now" | "later"

7. mind_map_interactive
   - prompt: "concept focus"
   - when: "now" (Generate Later and language unsupported)

8. mind_map_note
   - prompt: "concept focus"
   - language: "en" | "de" | "fr" (optional)
   - when: "now" (Generate Later unsupported)

9. flashcards
   - options.quantity: "FEWER" | "STANDARD" | "MORE"
   - options.difficulty: "EASY" | "MEDIUM" | "HARD"
   - options.include_images: false | true
   - when: "now" | "later"

10. quiz
    - options.question_types: ["MULTIPLE_CHOICE" | "FILL_IN_THE_BLANK" | "MULTIPLE_SELECT" | "SHORT_ANSWER"]
    - options.quantity: "FEWER" | "STANDARD" | "MORE"
    - options.difficulty: "EASY" | "MEDIUM" | "HARD"
    - when: "now" | "later"

11. data_table
    - prompt: "table layout and comparison instructions"
    - when: "now" (Generate Later unsupported)

Common Fields:
- "notebook_id": "REPLACE_WITH_NOTEBOOK_ID" (or the actual notebook UUID)
- "source_ids": ["uuid-1", "uuid-2"] (optional, omit to use all sources in notebook)
- "when": "now" (default) or "later" (Google queue, where supported)
