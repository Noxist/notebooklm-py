NotebookLM Studio Batch Generation

Auftragsverwaltung mit automatischer PDF-Zusammenstellung, 24-Stunden-Übersicht und flexiblen Download-Optionen.

Wähle dein Notebook aus, um dessen ID automatisch in die Jobs unten einzusetzen. 
Bereit. Keine neuen Aufträge gesendet.
📋 AI Prompt & JSON Format Spezifikation (Klicken zum Kopieren für ChatGPT / Claude / Gemini)

Kopiere diese Anleitung und füge sie in ChatGPT, Claude oder Gemini ein, damit die KI fertige Batch-Dateien für dich generiert:

Du erstellst eine JSON-Batch-Datei für NotebookLM Batch Studio.

Gib ausschliesslich valides JSON mit folgender Struktur aus:
{
  "combine_pdf": true,
  "pdf_title": "Titel des Dokuments",
  "jobs": [
    {
      "id": "eindeutige-id-001",
      "type": "report",
      "notebook_id": "REPLACE_WITH_NOTEBOOK_ID",
      "title": "Aussagekräftiger Titel",
      "prompt": "Genaue Instruktionen für den Prompt",
      "language": "de",
      "when": "now",
      "include_in_pdf": true,
      "pdf_order": 1,
      "options": {}
    }
  ]
}

PDF-Zusammenstellung:
- "combine_pdf": true (auf oberster Ebene: fasst fertige Ausgaben zu einem Gesamtdokument zusammen)
- "include_in_pdf": true | false (pro Job: ob dieser Prompt im PDF enthalten sein soll)
- "pdf_order": Ganzzahl (Reihenfolge an welcher Position im PDF eingefügt wird. Wird kein Wert angegeben, gilt automatisch die Sendereihenfolge)

Unterstützte Typen:
1. report
   - format: "BRIEFING_DOC" | "STUDY_GUIDE" | "BLOG_POST" | "CONCEPT_EXPLANATION" | "CUSTOM"
   - prompt: "Aufgabenstellung / Prompt"
   - language: "de" | "en"
2. slide_deck
   - format: "DETAILED_DECK" | "PRESENTER_SLIDES"
   - options.slide_length: "DEFAULT" | "SHORT"
3. quiz
   - options.question_types: ["MULTIPLE_CHOICE", "SHORT_ANSWER"]
   - options.difficulty: "EASY" | "MEDIUM" | "HARD"
4. flashcards
   - options.difficulty: "EASY" | "MEDIUM" | "HARD"
5. data_table
   - prompt: "Vergleichstabelle Instruktionen"
6. mind_map_note
   - prompt: "Konzeptfokus"
7. infographic
   - options.orientation: "LANDSCAPE" | "PORTRAIT" | "SQUARE"
   - options.style: "PROFESSIONAL" | "SKETCH_NOTE" | "EDITORIAL"
8. audio
   - options.audio_format: "DEEP_DIVE" | "BRIEF" | "DEBATE"
   - when: "now" | "later"
Auswahl: 0 ausgewählt
